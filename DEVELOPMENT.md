# Local development

This repository is PoJen Wang's customized pre-v1 al-folio site. It currently
builds with Jekyll 4.3.3 and Ruby 3.3. The upstream al-folio v1 line has moved to
a plugin-based architecture, so that migration should be handled as a separate,
reviewed project rather than mixed into a content update.

## macOS setup

Do not use Apple's system Ruby. Install a maintained Ruby and ImageMagick with
Homebrew:

```bash
brew install ruby@3.3 imagemagick

export PATH="/opt/homebrew/opt/ruby@3.3/bin:/opt/homebrew/lib/ruby/gems/3.3.0/bin:$PATH"
ruby --version
bundle --version
```

Install the locked dependencies inside the repository:

```bash
bundle config set --local path vendor/bundle
bundle install --jobs 2
```

`vendor/`, `.bundle/`, generated responsive images, and `_site/` are ignored.

## Build and preview

Build the same production site generated by CI:

```bash
JEKYLL_ENV=production bundle exec jekyll build
```

Run a local preview:

```bash
bundle exec jekyll serve --host 127.0.0.1 --port 4000
```

Open <http://127.0.0.1:4000/>. The wavelet article is at
`/blog/2024/wavelet-quantum-chemistry/`.

The build converts the existing notebook and regenerates responsive WebP images,
so a clean build can take roughly two minutes on Apple Silicon.

## Deployment

GitHub Actions builds pull requests without deploying them. A push to `master`
builds `_site/` and publishes it through the repository's existing deployment
workflow. Review a local production build before merging content to `master`.
